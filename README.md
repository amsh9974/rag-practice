# Innoligo M365 Licence & Cost Optimiser

A web app that turns Microsoft 365 admin-centre CSV exports into a costed
licence-waste report for UK SMEs, as the top of Innoligo's sales funnel.

See `SPEC.md` for the full brief, `CLAUDE.md` for stack/conventions, and
`PLAN.md` for the slice-by-slice build plan.

## Development

```bash
npm install
npm run dev
```

```bash
npm run build   # production build
npm run lint    # eslint
npm test        # vitest
```
